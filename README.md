# 📝 Python To-Do List Application

A command-line To-Do List application built with Python that allows users to manage daily tasks,
 track their progress, and save their data using JSON.

## ✨ Features

- ➕ Add new tasks
- 📋 View all tasks
- ✏️ Edit existing tasks
- 🗑️ Delete tasks
- 🔍 Search for tasks
- ✅ Mark tasks as completed
- ↩️ Unmark completed tasks
- 🧹 Delete all completed tasks
- ⭐ Change task priority
- 📊 View task statistics
- 💾 Save and load tasks using JSON

## 🛠️ Technologies

- **Python** — Application logic
- **JSON** — Task data storage

## 🚀 Getting Started

### Prerequisites

- Python 3.10 or later (adjust this to your actual minimum supported version).

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Mostafa-MAZER/ToDoList.git
   ```

2. Navigate to the project directory:

   ```bash
   cd ToDoList
   ```

3. Run the application:

   ```bash
   python main.py
   ```

> **Note:** Make sure the repository URL and entry-point filename match your actual GitHub project.

## 💻 Usage

Run the application and follow the command-line menu to manage your tasks.

You can add tasks, view your task list, update priorities, mark tasks as completed, search for tasks, and check your statistics.

## 💾 Data Storage

Tasks are stored in a JSON file so that they can be saved and loaded between application runs.
